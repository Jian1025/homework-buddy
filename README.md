## 🎯 About
Homework Buddy is a kid-friendly homework planner built for primary school students from Grade 3 to 6.
It turns homework time into a fun experience with blind-box rewards, pomodoro timers, progress tracking and gentle study reminders.
The whole UI uses a soft cartoon style, sky‑blue theme, emoji decorations and supports **Chinese / English language switching**.

> Core goal: Help kids build good homework habits with positive reinforcement instead of pressure.

## 🧩 Core Features
- 🎁 **Homework Blind Box Reward**
  Earn one blind box draw after finishing each task. Reward pool includes snacks, animation time, pocket money and virtual points. Rewards can be configured by parents. All records are saved under your account.
- 📅 **Calendar & Task Input**
  Slide to switch dates or adjust date manually. Mark difficulty level for every homework item. Support text input and voice input for quick task creation.
- ⏱️ **Pomodoro Countdown Timer**
  Set independent countdown for each homework task. Start / pause / reset controls. Soft alarm rings when time is up.
- 📊 **Homework Progress Management**
  View and manually update task status: Not Started / In Progress / Completed. Delete any task freely.
- 🔒 **Study Lock Mode**
  Set your unlock password. Block entertainment apps on your device during study sessions to reduce distractions.
- ☁️ **Account & Cloud Save**
  Log in to sync your homework list, blind box records and settings. Data can be restored across devices.
- 🤖 **Gentle Study Monitoring**
  Detect whether the student is doing paper-and-pencil work. The cartoon mascot will pop up friendly reminders if off-task.
- 🌐 **Bilingual Support**
  One-click toggle between Chinese and English. All interface text updates synchronously.

🎯 项目简介
作业小伙伴（Homework Buddy）是一款专为小学三至六年级学生打造的作业规划工具。它通过盲盒奖励、番茄钟计时、进度追踪和温和学习提醒，让写作业变得有趣。整体界面采用柔和卡通风格、天蓝色主题，搭配表情装饰，支持中英文切换。
核心目标：用正向激励的方式帮助孩子养成良好的写作业习惯，而非施压。
🧩 核心功能
🎁 作业盲盒奖励：每完成一项任务可抽取一次盲盒。奖励池包含零食、看动画时间、零花钱、虚拟积分，奖励内容支持家长自定义。所有记录保存在账号内。
📅 日历与任务录入：滑动切换日期，也可手动调整日期；可为每项作业标注难度；支持文字输入、语音快速录入任务。
⏱️ 番茄倒计时：每项作业可单独设置倒计时，支持开始 / 暂停 / 重置；时间结束时有轻柔提示音。
📊 作业进度管理：查看并手动修改任务状态：未开始 / 进行中 / 已完成，可自由删除任务。
🔒 学习锁定模式：设置解锁密码，学习时段屏蔽设备上的娱乐应用，减少干扰。
☁️ 账号与云同步：登录账号即可同步作业清单、盲盒记录与设置，多设备之间可以恢复数据。
🤖 温和学习监督：识别孩子是否在进行纸笔学习；分心时卡通吉祥物会弹出友好提醒。
🌐 双语支持：一键切换中英文，界面文字同步更新。
